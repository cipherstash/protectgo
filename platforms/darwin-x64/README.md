# Darwin x64 (Intel)

This directory contains the compiled native library for Intel-based Macs.

- `libprotect_ffi.a` - Static library for linking with Go applications

Generated for:
- macOS 10.15+ (Catalina and later)
- Intel x86_64 processors
- x64 architecture

## Usage

This library is automatically selected when building Go applications on Intel Macs.
