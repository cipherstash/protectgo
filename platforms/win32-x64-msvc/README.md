# Windows x64 MSVC

This directory contains the compiled native library for Windows on x86_64 architecture.

- `libprotect_ffi.a` - Static library for linking with Go applications

Generated for:
- Windows 10/11
- Intel x86_64/AMD64 processors
- Microsoft Visual C++ runtime
- 64-bit architecture

## Usage

This library is automatically selected when building Go applications on x64 Windows systems.
