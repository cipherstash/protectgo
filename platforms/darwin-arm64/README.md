# Darwin ARM64 (Apple Silicon)

This directory contains the compiled native library for Apple Silicon (ARM64) Macs.

- `libprotect_ffi.a` - Static library for linking with Go applications

Generated for:
- macOS 11.0+ (Big Sur and later)
- Apple Silicon (M1, M2, M3+ processors)
- ARM64 architecture

## Usage

This library is automatically selected when building Go applications on Apple Silicon Macs.
